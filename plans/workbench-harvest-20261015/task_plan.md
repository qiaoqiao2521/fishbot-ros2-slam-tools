# 最近成果统一到 FishBot 工作台

## Goal
用户确认将最近收获汇总到 FishBot 网页工作台。复用现有蓝白布局，提供能力入口、验收快照、失败明细与后续候选。

## Scope
新增 /workbench；保留 /、/radar、/simulation、/cooperation。汇总导航地图、车臂运输、实际RGB、SpatialLM、视频事件、Arena。原56例和新增3回合分别展示。历史报告提供同源审定摘要；不公开原始日志、地图、私人路径或账户信息。

## Constraints
不启动ROS动作、仿真、推理、GPU或云资源。外部分析台仅导航及固定GET入口检查，不复制审批/导出写协议，不自动启动工具。服务在线与历史验收分别标记。手机不把localhost误认成工作台电脑。

## Design
沿用蓝白工作面：#14263d导航、#2563eb操作、#f4f6fb背景、#ffffff正文、#64748b注释、#b45309待验收。系统中文字体。首页按空间→规划→运输→分析组织入口；验证区独立显示冻结日期与明细，拒绝同尺寸大数字卡片。响应式五区导航，失败可筛选、原因可定位。

## Acceptance
- 六项近期能力有入口、当前边界和来源；服务未运行不伪装在线。
- 原56例唯一且总数38完成/7正确取消/11失败；新增1取消+2运输单列。
- 总览无运动控制挂载或写请求；同源静态报告可从网页和手机查看。
- 路由、数据、服务检查及页面合同通过；相关前端全套、type/lint/build通过。
- 独立浏览器1440/390px检查导航、过滤、来源、未知/离线状态和零写；不启动ROS。
- 根串行更新PROJECT/研究入口、知识状态及既有远端提交推送。

## State
实施与本轮验收完成。root维护数据、路由、计划和交付；worker已停止源码写。近期材料以项目当前报告为准，不把历史服务HTTP200当当前在线。既有远端交付由root串行确认，见progress。
