# 航点草稿保护与15秒对比

## Goal
把既有巡逻和禁区模块接成可见、可恢复的草稿控制层。地图显示冲突红线，选点越过软件规则时吸附到首次冲突前；掉线保留航点，重连核对草稿和规则版本。交付实际15秒对比录屏。

## Scope and constraints
- 复用原MapZonesManager、map-rules CAS、任务UUID与Nav2 owner。草稿通过不代表真实任务成功。
- 吸附使用0.13m圆足迹并留0.01m额外余量。地图实体占用目标直接拒绝；不生成穿过障碍的执行路径。
- localStorage只保存航点、返航、名称、地图/域、规则版本与草稿revision_id。绝不保存运动请求时间、自动重发命令或恢复未知任务。
- Web Locks串行执行缓存CAS；无锁时仅保留内存，不宣称跨标签页原子持久化。
- 保留122/API9072/网页5181与121原演示。只做浏览器断流注入，无ROS新任务、网络或实体操作。
- 对照录屏明确标注关闭预检的画线示意，不伪造撞墙、卡死或真机效果。录屏及运行证据本地保留。
