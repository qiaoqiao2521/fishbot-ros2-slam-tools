# Findings

- 既有页面只有文字几何提示，点击按两位小数加入航点；需要避免把吸附点再次舍入到禁区。
- 原后端已验证map_id/rules_revision，沿用该CAS。revision_id仅为浏览器草稿身份，不能冒充ROS执行UUID。
- 旧页面同进程掉线时保留React状态，重新载入或map generation变化会清空；持久缓存补这一缺口。
- 复用Web Locks与localStorage，无需新服务/调度/数据库。缺少Web Locks时明示内存模式。
- 沿用Wiki/ROS2 与 FishBot第12节：未知原UUID只读恢复，不自动重发；第19/20节：来源、观测、原生动作与物理评分独立。草稿录屏不外推新的物理验收。
- 独立审查修复三项：航点撤销只回滚航点/返航，不覆盖后来修改的名称；模板载入与选点统一0.13m；同地图规则变化清除旧安全吸附标记。直线冲突只提示，合法两端仍可显式交给原Nav2绕行。
- 现有规则reducer正确拒绝revision倒退。浏览器注入较高版本后，结束夹具必须重新载入页面，不能把拒绝旧版本误报为重连故障。
- 缓存读取和写入都在同key Web Lock内，冲突不覆盖。同步几何确认不能宣称从localStorage到ROS派发跨系统原子性；后端原owner继续裁决。
