# 补全语音任务框架

## Goal
将1c74dab文字原型补成FishBot网页可用的语音任务入口，复用现有ASR、ROS任务所有权与最终守卫。修复否定、停车优先与过期重放，支持文字/真实音频预览和显式任务执行；实际隔离ROS/MuJoCo验收。

## Scope and constraints
只操作代码和仿真，不接实体、不刷固件、不动网络或GPU。原107/114实例及工作台快照保持。语音不直接发布最终cmd_vel；任务完成按原生回执与物理评分验证。当前无实车。保持原失败与知识经验边界。

## Phases
1. complete：核对现有任务API、复用官方Vosk、冻结协议与独占121域。
2. complete：意图/来源/去重、真实ASR与原任务适配完成；BACKWARD使用原生BackUp。
3. complete：工作台语音面板、录音/文件/文字预览与显式确认。
4. complete：离线/浏览器、实际导航、完整运输、原生倒车和网页派发已验。
5. complete：文档入口、知识判断、独立审查和Git交付已完成，实施提交b6b09ea已推送既有main。

## Ownership
root拥有ASR适配、计划/共享入口、集成、实际验收和Git。worker划分核心解析与ROS wrapper、任务网关、前端组件；各自只写约定文件，不启动ROS/GPU。

## Acceptance
三类否定/停止/后退原误判修复；新鲜度/会话/序号/去重和未知回执不重发。实际音频经现成ASR产生文字，静音/失败不产生动作。网页无自动录音/执行，有明确状态、拒绝原因与录音结束。导航/取消/运输等支持项复用原owner，未配置回充不冒充充电成功。至少实际导航及移动取消闭环，并按可用配置验收车臂命令。相关回归、类型/lint/build与网页验证通过；旧验收数字不改。

## Next Step
本轮完成。保留空闲演示入口；生产ASR、回充适配和多客户端仲裁需新需求与独立验收。
